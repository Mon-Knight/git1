# 模块边界 — AI World Engine

## 文档目的

明确 AI World Engine 各模块的职责边界，防止后续开发中出现模块职责混杂、重复造功能、跨模块污染等问题。

## 1. 世界资料库

**负责**：
- 角色管理（创建/编辑/删除/查看）
- 势力管理（创建/编辑/删除/查看）
- 地点管理（创建/编辑/删除/查看）
- 规则管理（创建/编辑/删除/查看）
- 历史事件管理（创建/编辑/删除/查看、正史标记）
- 时间线查看（正史/全部/非正史筛选）

**不负责**：
- 正文生成
- 风格润色
- 分卷规划
- 章节规划
- AI 推演执行

**边界规则**：
- 角色、势力、地点、规则、事件严格属于一个世界
- 跨世界引用不允许（一个世界的角色不能出现在另一个世界的事件中）

## 2. AI 推演

**负责**：
- 普通世界推演（`simulation_type: general/world_simulation`）
- 推演记录管理（列表/详情/采纳/分支）
- 分支记录管理
- 采纳正史流程（`is_canon=True`, `source_type=simulation`）
- 保存分支流程

**不负责**：
- 自动写入小说正文
- 自动决定主线小说方案
- 全书演化推演（那属于小说工程模块）

**边界规则**：
- 所有 AI 生成结果必须先保存为 `simulation_records`，状态为 `pending`
- 只有用户手动操作后才能改变状态
- 采纳正史创建 `historical_events`，分支创建 `branches`

## 3. 创作资产

**负责**：
- 风格方案（StyleProfile）创建/编辑/删除/全局方案
- 剧情时间点（PlotAnchor）创建/编辑/删除
- 创作上下文包（ContextPackage）创建/编辑/删除/预览
- 供生成任务（全书演化、分卷大纲、正文）复用的上下文资产管理

**不负责**：
- 直接生成正文
- 自动分析参考小说
- 自动修改世界设定
- 自动采纳 AI 生成内容

**边界规则**：
- 上下文包只是引用组合，不复制内容
- 上下文包引用的所有资产必须属于同一个世界
- 全局风格方案（`world_id=NULL`）可在所有世界使用
- 删除被上下文包引用的资产时，禁止删除并提示先移除引用

## 4. 小说工程

**负责**：
- 全书演化推演（`/novel/evolution`）
- 全书演化方案列表/详情（`/novel/evolutions`）
- 方案状态管理（主线/备选/废弃）
- 分卷大纲生成（v1.8.0+）
- 章节大纲生成（v1.9.0+）
- 正文生成（v2.0.0+）
- 正文版本管理（v2.1.0+）
- 润色（v2.1.0+）

**不负责**：
- 基础世界 CRUD（属于世界资料库）
- 数据备份恢复（属于数据管理）
- AI 设置（属于设置模块）
- 推演记录管理（属于 AI 推演模块）

**边界规则**：
- 全书演化方案的 `simulation_type` 固定为 `novel_evolution`
- 方案状态只修改 `simulation_records.status`，不创建 `historical_events`
- 方案状态映射：`pending→待确认`, `adopted→主线方案`, `branched→备选方案`, `discarded→已废弃`
- 后续分卷大纲和章节大纲必须在主线方案基础上生成

## 5. 检查中心

**负责**：
- 设定矛盾检查（规则式检测 + AI 补充分析）
- 角色行为合理性检查
- 输出检查报告
- 给出修正建议

**未来负责**（v2.2.0+）：
- 正文一致性检查
- 风格一致性检查

**不负责**：
- 自动修改正史（只能建议，不能修改）
- 自动修改正文
- 自动删除设定
- 自动解决矛盾

**边界规则**：
- 检查结果不自动改变任何数据
- 用户可以手动采纳检查建议

## 6. 数据管理

**负责**：
- 单世界 JSON 导出
- 世界 JSON 导入
- 数据库备份
- 数据库恢复
- 导出/导入兼容所有数据表

**不负责**：
- AI 生成
- 修改创作逻辑
- 云同步
- 数据库迁移（Alembic 属于 v2.4.0+）

**边界规则**：
- 导出不包含 API Key / .env / 日志
- 导入时自动创建新世界，ID 重新映射
- 重名世界自动重命名
- 恢复前自动备份当前数据库
- EXE 模式 backups 路径为 `%LOCALAPPDATA%/AIWorldEngine/backups/`

## 7. 设置

**负责**：
- AI 模型配置（Base URL / API Key / Model / 温度 / Token 限制）
- 应用信息（版本号、模式状态）

**不负责**：
- 世界设定
- 小说参数

## 模块依赖关系

```
设置 (Settings)          ← 被所有模块引用
世界项目 (Worlds)        ← 所有模块的基础
├── 世界资料库           ← 依赖世界项目
├── AI 推演              ← 依赖世界项目、世界资料库、设置
├── 创作资产             ← 依赖世界项目、AI 推演（引用推演记录）
├── 小说工程             ← 依赖世界项目、创作资产、设置
├── 检查中心             ← 依赖世界项目、世界资料库、设置
└── 数据管理             ← 依赖世界项目、所有数据表
```

注：箭头表示"依赖"方向。例如小说工程依赖创作资产提供的上下文包。
