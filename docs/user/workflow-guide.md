# 创作流程指南

## 推荐创作流程

### 1. 创建世界
访问 `/worlds/new`，填写世界名称、类型、时代和基调。

### 2. 填充设定库
在世界控制台中，通过设定库分组添加：
- **角色**：主角、配角、反派
- **势力**：国家、组织、派系
- **地点**：城市、区域、关键场景
- **规则**：魔法体系、物理法则、社会规则

### 3. 建立剧情历史
- 创建关键历史事件（正史）
- 使用时间线查看事件顺序

### 4. AI 推演与分支
- 进入 AI 推演，基于现有设定提问
- 查看推演记录，审核结果
- 采纳为正史或保存为分支

### 5. 检查一致性
- 运行设定矛盾检查
- 运行角色行为合理性检查

### 6. 小说工程
- 创建创作上下文包（组合风格方案、剧情时间点）
- 运行全书演化推演
- 审核演化方案

## 核心规则

- **AI 推演结果不会自动写入正史**，必须先保存为推演记录
- 用户需手动审核后选择"采纳为正史"或"保存为分支"
- 分支记录不影响正史时间线
