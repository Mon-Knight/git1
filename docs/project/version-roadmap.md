## 各版本详细目标

### v1.7.0：全书演化推演增强版【已完成】

- 基于 ContextPackage 生成 12 章节结构化全书演化方案
- 方案列表 / 详情 / 主线 / 备选 / 废弃状态管理
- 不自动写入正史

### v1.7.1：防混乱开发规范与应用化路线整理【当前版本】

**目标**：
- 建立开发规范（development-rules.md）
- 建立 Agent 任务规则（agent-task-rules.md）
- 建立 UI 信息架构文档（ui-information-architecture.md）
- 建立模块边界文档（module-boundaries.md）
- 建立版本路线文档（version-roadmap.md）
- 修正长期版本路线

**不做**：任何新业务功能、数据库变更、UI 重构

### v1.7.2：统一应用壳布局

**目标**：
- 顶部栏（应用标题、当前世界、AI 状态指示器）
- 左侧导航（工作台/世界项目/小说工程/创作资产/AI 推演/检查中心/数据管理/设置）
- 主内容区（嵌入或导航到现有页面）
- 不删除旧路由，旧 URL 继续可访问
- 不重写所有模板，加壳不加芯

### v1.7.3：主工作台首页

**目标**：
- 最近世界列表
- 最近上下文包
- 最近全书演化方案
- 待处理推演数量
- 主线/备选方案数量
- AI 模式状态
- 快捷操作入口

### v1.7.4：世界控制台

**目标**：
- 将 `/worlds/{id}` 从模块入口页升级为世界控制台
- 显示该世界的创作状态摘要
- 显示推荐下一步操作
- 保留所有旧模块入口

### v1.7.5：模块分组与二级导航

**目标**：
- 设定库（角色/势力/地点/规则）
- 剧情历史（历史事件/时间线）
- AI 推演（推演/记录/分支）
- 小说工程（全书演化/演化解列表等）
- 创作资产（风格/时间点/上下文包）
- 检查中心（设定矛盾/行为检查）
- 数据与设置（导出导入备份恢复/AI 设置）

### v1.7.6：阶段性整理、文档体系重整与 EXE 验证【当前版本】

**目标**：
- 重构 README.md 结构
- 重整 docs 文档体系（user/project/technical/design）
- 清理重复 CSS、统一命名
- 补齐 CHANGELOG、version-roadmap
- 补充测试覆盖
- 重新构建并验证 EXE

**不做**：任何新业务功能、数据库变更

### v1.7.7：桌面端窗口大小控制、响应式 UI 与 2K 适配

**目标**：
- 桌面端窗口初始大小可配置
- 响应式布局适配 2K 分辨率
- 侧栏折叠/展开
- 不改为移动端适配

### v1.7.8：导出文件位置选择与导出体验优化

**目标**：
- 导出文件支持选择保存位置
- 导出进度反馈
- 导入文件选择器优化

### v1.7.9：设定库 AI 推演基础版

**目标**：
- 基于已有设定，AI 推荐可能需要的角色/势力/地点/规则
- 生成候选设定建议
- 用户审核采纳

### v1.7.10：候选设定采纳与测试补齐

**目标**：
- 候选设定采纳流程完善
- 测试覆盖补齐
- v1.7.x 阶段收尾

### v1.8.0：基于主线全书演化方案的分卷大纲生成

**目标**：
- 选择已标为主线方案的 novel_evolution 记录
- 选择 ContextPackage（可选，继承全书演化时的上下文包）
- AI 生成分卷大纲（每卷包含故事线、关键事件、阶段目标）
- 保存分卷方案
- 状态管理：草稿/已采用/备选/废弃
- **不做**章节大纲、正文生成

### v1.9.0：章节大纲生成

**目标**：
- 基于已采用的分卷生成章节大纲
- 每章包含摘要、关键场景、角色参与
- **不生成**正文

### v2.0.0：正文初稿生成

**目标**：
- 基于上下文包、主线演化、分卷、章节、风格方案生成正文初稿
- 保存正文版本
- 支持 Markdown 输出格式

### v2.1.0：正文版本管理与风格润色

**目标**：
- 多正文版本管理
- 润色前后对比
- 风格方案约束润色方向

### v2.2.0：长篇一致性检查增强

**目标**：
- 设定一致性检查
- 时间线一致性检查
- 人物行为一致性检查
- 未公开秘密检查
- 能力限制检查
- 风格一致性检查

### v2.3.0：参考小说风格画像

**目标**：
- 导入参考小说片段
- 提取抽象写作风格画像（用词习惯、句式结构、描写密度等）
- 不复制原文
- 不模仿专有角色/桥段/设定

### v2.4.0+：成熟应用工程化能力

**目标**：
- Alembic 数据库迁移
- 安装包（MSI/DMG）
- 自动备份
- 全文搜索
- 多小说/外传/平行线
- 本地模型深度接入
